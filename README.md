# TQQQ 웅덩이 매수 신호지수

TQQQ를 장기 관점으로 볼 때, 지금은 평온한지 아니면 분할 매수를 고민할 만큼 빠진 “웅덩이”인지 점수로 보여 주는 화면입니다.

## 점수가 의미하는 것

| 구간 | 이름 | 한 줄 |
|---|---|---|
| 70점대 | 소형 웅덩이 | 걱정만 있던 하락에 가깝습니다. |
| 80점대 | 중형 웅덩이 | 실제 사건이 터진 조정에 가깝습니다. |
| 90점대 | 대형 웅덩이 | 드물고 깊은 구간입니다. 금리 꺾임과 함께 보는 편이 보수적입니다. |

점수는 하락률, 주간·일간 RSI, VIX, 200일선, CNN 공포탐욕 등을 섞어 만든 **참고용 학습 점수**입니다. 투자 조언이 아닙니다.

## 화면에서 같이 보는 것

- 오늘 점수와 S&P 500·나스닥 종가
- 그날 시장을 대표하는 짧은 시황 문장
- QQQ·SOXX 주봉 추세(CCI 30)
- 원할 때만 여는 QQQ 일봉·헤이킨 아시 차트

데이터는 한국시간 매일 06:30에 미국 정규장 종가 기준으로 맞춥니다.
