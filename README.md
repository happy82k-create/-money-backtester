# 📈 돈을벌자 백테스터

SOXL / TQQQ 일별 종가로 " 매매법의 수익률을 시뮬레이션하는 웹 도구입니다.

## 1. 실행 방법 (가장 쉬운 방법)

1. 프로젝트 폴더의 **`run_app.bat`** 을 더블클릭
2. 검은 창이 뜨고 잠시 후 브라우저가 열립니다. 안 열리면 주소창에 `http://localhost:8501` 입력
3. 끌 때는 검은 창을 닫으면 됩니다.

명령어로 실행하려면 (PowerShell, 프로젝트 폴더에서):

```powershell
.\.venv\Scripts\python -m streamlit run app.py
```

## 2. 화면 사용법

맨 위 메뉴에서 화면을 고릅니다.

- **1. TQQQ 장기투자**: 웅덩이 매수 신호지수. 오늘 점수와 70/80/90 구간을 봅니다.
- **2. TQQQ 단기투자**: 돈을벌자 / 무한매수법 V4 백테스트. 좁은 화면에서는 왼쪽 절반이 설정, 오른쪽 절반이 결과입니다.

왼쪽 사이드바에서 조건을 고르면 결과가 바로 바뀝니다.

| 설정 | 설명 |
|---|---|
| 전략 | **돈을벌자**(기존 6분할) 또는 **무한매수법 V4**(20/30/40분할). 사이드바 맨 위에서 고릅니다 |
| 종목 | SOXL 또는 TQQQ |
| 시작일 / 종료일 | 기본: 2020-01-02 ~ 보유 데이터 마지막 날 |

| 익절 | +0.01% / +1.00% / +2.00% / 직접 입력 |
| 타임컷 | 10일 / 12일 / 직접 입력 (거래일 기준) |
| 고급 설정 | 매수 기준 하락 %(기본 0.10), 수수료·슬리피지, 복리, 소수점 주식 |
| 🔄 최신 데이터 갱신 | 오늘까지의 종가를 다시 받아 저장 (인터넷 필요) |

탭 설명 (돈을벌자)

- **📊 결과**: 최종 자산·CAGR·MDD·승률 등 + Buy&Hold 비교 차트
- **🧾 거래 내역**: 거래별 상세(CSV 다운로드), 미청산 포지션, 일별 계좌 상태
- **🔬 조건 비교**: 익절 × 타임컷, 균등 vs 차등 비교표
- **🗺️ 히트맵**: 익절% × 타임컷 일수 49개 조합 전체를 색깔 지도로 비교 (버튼 눌러 계산)
- **📖 전략 규칙**: 현재 설정이 반영된 규칙 요약

탭 설명 (무한매수법 V4)

- **📊 결과**: 최종 자산·CAGR·MDD·사이클 승률 + Buy&Hold 비교, 회차 T 차트
- **🧾 매수·매도**: 체결별 가격·수량·T·별지점·실현/평가 수익률 (CSV)
- **🔁 사이클**: 사이클별 수익률 표와 막대 그래프
- **🔬 20 vs 40**: 같은 조건에서 20/30/40분할 비교
- **📖 전략 규칙**: V4.0 일반모드·리버스모드 요약 (종가 단순화 모델)

## 3. 전략 규칙 (이 백테스터의 해석)

- 모든 주문은 **LOC**, 조건 충족 시 **그날 종가**에 체결
- **매수**: 전일 종가 × (1 − 0.10%) 이하로 마감 → 1분할 매수 (하루 최대 1건, 정액 매수 없음)
- **익절**: 티어(매수 건)별 진입가 × (1 + 익절%) 이상으로 마감 → 해당 티어만 매도, 진입 당일은 매도 불가
- **타임컷**: 진입 후 N거래일째 종가에 미체결 포지션 강제 매도, 같은 날 매수 조건 충족 시 신규 매수 가능
- 익절로 빈 티어는 **다음 거래일**부터 매수 가능
- 초기자본 기준 고정 분할(복리 옵션 있음), 주식은 정수 단위(소수점 옵션 있음), 수수료 기본 0%

## 4. 폴더 구조

```
backtest1/
├─ app.py              웹사이트(Streamlit)
├─ run_app.bat         더블클릭 실행 파일
├─ requirements.txt    필요한 라이브러리 목록
├─ data/               soxl.csv, tqqq.csv (일별 종가, 분할 조정·배당 미반영)
├─ src/
│  ├─ engine.py        백테스트 엔진
│  ├─ fetch_data.py    데이터 수집/갱신
│  ├─ verify_data.py   데이터 품질 리포트
│  ├─ verify_trades.py 거래 검증(불변 조건 + 독립 재구현 대조)
│  └─ compare.py       조건 24개 조합 비교(터미널용)
└─ tests/test_engine.py  엔진 단위 테스트
```

## 5. 자주 쓰는 명령 (PowerShell, 프로젝트 폴더에서)

```powershell
# 데이터 갱신 (오늘까지)
.\.venv\Scripts\python src\fetch_data.py

# 엔진 단위 테스트
.\.venv\Scripts\python -m unittest discover -s tests

# 실데이터 거래 검증
cd src; ..\.venv\Scripts\python verify_trades.py
```

## 6. 처음부터 다시 설치할 때

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python src\fetch_data.py
```
